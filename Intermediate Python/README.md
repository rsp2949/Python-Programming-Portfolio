# Intermediate Python — Practical Exercises

A collection of nine Python exercises focused on language features, functional programming, resource handling and concurrent execution.

## Exercise Overview

1. Transforming and filtering collections with comprehensions
2. Processing data using lambda expressions and functional tools
3. Building custom iterators and generator functions
4. Extending functions through decorators
5. Handling runtime errors and validating input
6. Managing external files through Python
7. Searching and modifying text with regular expressions
8. Running multiple tasks using threads
9. Managing resources with context managers

## Learning Outcomes
- Write concise collection-processing expressions.
- Understand lazy evaluation and iteration.
- Apply decorators to modify function behavior.
- Handle unexpected runtime conditions.
- Perform file operations safely.
- Extract and validate patterns in text.
- Understand concurrent execution.
- Manage resources with automatic cleanup.

## Completion
All nine exercises are maintained as separate Python files with practical examples and sample outputs.
