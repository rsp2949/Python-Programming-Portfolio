# Python OOP — Practical Exercises

A collection of 13 exercises exploring object-oriented programming through real-world examples and class-based implementations.

## Exercise Overview

1. Building classes and creating objects
2. Initializing objects using constructors
3. Extending functionality through inheritance
4. Applying polymorphism with overridden methods
5. Protecting attributes through encapsulation
6. Using abstraction to define common behavior
7. Understanding shared and individual object attributes
8. Working with static and class-level methods
9. Supporting flexible method arguments
10. Customizing operators for user-defined objects
11. Implementing Python special methods
12. Combining objects through composition
13. Inheriting functionality from multiple parent classes

## Skills Developed
- Object creation and initialization
- Reusable class design
- Inheritance and method resolution
- Encapsulation and abstraction
- Dynamic method behavior
- Custom operator implementation
- Object composition and relationships

## Learning Goal
These exercises demonstrate how Python classes can represent real-world entities, manage data, and organize application logic into reusable components.

## Completion Status
All 13 OOP exercises are organized as separate Python programs.
