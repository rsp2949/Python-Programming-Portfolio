# Python Programming Fundamentals

This directory includes 11 introductory Python exercises designed to build programming skills through simple implementations and practical examples.

## Exercise List

1. Displaying messages using Python
2. Working with variables and data types
3. Accepting input from users
4. Performing string manipulations
5. Creating and modifying lists
6. Understanding tuple operations
7. Managing information with dictionaries
8. Using iteration statements
9. Creating reusable functions
10. Solving problems through recursion
11. Exploring additional Python features

## Learning Outcomes
- Understand basic Python program structure.
- Store and process different types of information.
- Perform operations on strings and collections.
- Apply conditional and looping concepts.
- Create modular programs using functions.
- Understand recursive execution.
- Explore useful Python language features.

## Completion
All 11 exercises are organized as individual Python files with sample outputs and practical demonstrations.
